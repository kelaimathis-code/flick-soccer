# ⚽ Flick Soccer

Jeu de foot de table en pichenettes, 5 contre 5, au tour par tour — inspiré des jeux type « Soccer 5 ».
100 % HTML5 Canvas + JavaScript, un seul fichier, aucune dépendance.

## Jouer
Ouvre simplement `index.html` dans ton navigateur (ordinateur ou mobile).

## Règles
- Clique sur un de tes palets, **tire en arrière** comme un lance-pierre, puis **relâche** pour tirer.
- Chaque équipe joue un coup à tour de rôle (15 secondes par tour).
- Marque dans le but adverse ! Le premier à 1, 3 ou 5 buts gagne.

## Fonctionnalités
- Mode **contre l'IA** (facile / normal / difficile) ou **2 joueurs** sur le même écran
- 12 équipes nationales avec leurs drapeaux
- Physique réaliste : rebonds, poteaux, filets, frottements
- Sons générés (Web Audio), compatible tactile
